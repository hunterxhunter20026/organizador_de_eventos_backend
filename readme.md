# Organizador de Eventos - BackEnd

## Descripcion

Este es el Backend API encargado de guardar toda la arquitectura, gestionar los datos y asegurar que todo funcione correctamente detras de la interfaz de usuario

---

## Tecnologias utilizadas
Java
Spring boot

## Base de datos
Supabase - PostgreSQL

## Instalacion y ejecucion local
1. Clonar el repositorio
```bash
git clone <URL_DEL_REPOSITORIO>
```

2. Ingresar al directorio del proyecto
```bash
cd organizador_de__eventos_backend
```
